Ptah compares the state you want with the state a database has, then produces a
change you can inspect before it runs. Schema work can land as versioned SQL
files or as a direct apply. Persistent model output uses a separate candidate,
verification, cutover, and rollback lifecycle.

The default quick start creates and verifies a SQLite database in about five
minutes. It needs no database server, Docker, or Go toolchain.

## Three product domains

### Versioned migrations

Keep ordered SQL files in your repository when a change must be reviewed,
replayed across environments, and represented in deployment history.

[Start with a versioned migration](./start/quick-start-migrations/) or open the
[versioned workflow overview](./versioned/overview/).

### Direct schema changes

Keep a desired schema and let Ptah plan the SQL that makes a target database
match it. This path suits a database with one clear owner and changes that do
not need a committed migration file.

[Run the default quick start](./start/quick-start/) or open the
[direct workflow overview](./direct/overview/).

### Inference migrations

Keep the active generation available while Ptah builds, catches up, and verifies
a candidate generation. Cutover changes the active pointer only after the
candidate passes the required checks.

[Check whether inference migrations apply](./inference/overview/).

## Evidence and compatibility

Support levels describe what this repository exercises, not what a server is
allowed to do. The [database support matrix](./databases/support-matrix/) is
generated from the same release-line declaration used by CI.

Atlas compatibility is a separate journey through the `ptah-compat` binary.
The [Atlas overview](./atlas/overview/) distinguishes default compatibility,
strict Community Edition mode, native Ptah, measured parity, and retained
divergences. The native `ptah` binary does not register Atlas command paths.

Ptah is an independent MIT-licensed implementation. The
[license boundary](./atlas/license-boundary/) records the provenance policy.
