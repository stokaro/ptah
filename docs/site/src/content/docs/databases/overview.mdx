Start with measured support, then open the guide for the target engine. A
dialect name tells Ptah which SQL rules to use; a release-line support level
tells you what this repository continuously exercises. Neither is a promise
that every construct renders on every target.

## Choose by engine

The sidebar includes focused guidance for SQL Server, Oracle, ClickHouse, and
distributed SQL engines. The official [YDB](../../extend/providers/ydb/),
[Spanner](../../extend/providers/spanner/), and
[DuckDB](../../extend/providers/duckdb/) integrations run as separate providers
and document their own support scope. For built-in engines, the generated
support matrix and live capability output take precedence when they disagree
with an engine page.
